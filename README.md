
🌸 Iris Flower Classification

📌 About the Project

This project is a simple Machine Learning classification project using the Iris flower dataset.
The goal is to predict which type of Iris flower a given flower belongs to based on its measurements.
The project compares six different Machine Learning algorithms and checks their accuracy on the test data.

📊 Dataset

The Iris dataset contains measurements of three types of Iris flowers:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The four input features are:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

🤖 Machine Learning Algorithms Used

Six classification algorithms were trained and compared:

1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbors (KNN)
4. Support Vector Machine (SVM)
5. Naive Bayes
6. Random Forest

📈 Model Evaluation

The models were evaluated using accuracy on the test dataset.
In this particular train-test split, KNN achieved the highest accuracy of 1.0 (100%).
This result applies to this specific test data and does not mean KNN will always perform best on every dataset.
